# Assignment 4: Style Transfer

## Requirements
- Internet Access
- Python 3
- Pillow
- matplotlib
- numpy
- PyTorch
- torchvision

## How to Run
Make sure your content and style images are in png format and labelled as 'content.png' and 'style.png' respectively. Place your content and style image in the same directory as the Style_Transfer_Excercise.ipynb, then open Style_Transfer_Excercise.ipynb and run all cells in order.
